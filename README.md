# 6th WIMPA · Washington International Mobile Photography Awards

Static website for the 6th Washington International Mobile Photography Awards.

- Open `index.html` in a browser, or serve the folder with any static web server.
- Pages: Home, Winners 2026, Past Winners, Categories & Rules, Jury, About.
- `assets/data.js` holds the winners data; `images/w` (large) and `images/t` (thumbnails) hold the photos.
- `_build/` contains the scripts that generated the data and images from the original contest folders.

All photographs are copyright of their respective photographers.
